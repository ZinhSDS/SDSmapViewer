# SDSmapViewer

A high-performance, standalone desktop utility built using Pygame-ce to view Supreme Duelist Stickman custom maps (`.fun` files). 

This tool is designed specifically for map creators and community members to inspect, showcase natively on Windows without needing to launch the game or install external dependencies.

---

##  Features

* **Built for Scale:** Includes custom memory and rendering optimization capable of seamlessly parsing and drawing massive files.
* **Zero Setup:** Compiled as a single, standalone executable—no Python runtime or environment configurations required.
* **Technical Metrics Display:** Real-time HUD tracking total objects, visible counts, active cache size, and file weight.

---

##  Getting Started

1. Head over to the **Releases** tab on the right side of this repository.
2. Download the latest pre-release `.zip` bundle.
3. Extract the folder, run the executable, and input the path to your target `.fun` file when prompted.

---

##  Requirements (For Source Execution)

If you prefer to run or modify the raw source code (`.py`) instead of using the compiled executable, you will need:
* Python 3.10+
* `pygame-ce` library (`pip install pygame-ce`)
* `sdsmap` library (`pip install sdsmap`)
